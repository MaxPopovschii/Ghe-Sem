# GHE SEM — demo trasporto pubblico Milano

Il prototipo usa dati simulati per posizioni, arrivi e avvisi. Non è collegato a un feed ATM realtime e non deve essere usato per decisioni di viaggio.

## Avvio

Richiede Node.js 22 e npm.

```sh
npm ci
npm run dev
```

## Verifica

```sh
npm run build
```

Per lo stato dell'integrazione consulta [REAL_API_GUIDE.md](REAL_API_GUIDE.md). Non sono richieste chiavi API.
